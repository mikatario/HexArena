# ヘックス・アリーナ（8人オートバトル）

8人で戦うオートバトルゲームです。ひとりでもAI 7人と遊べます。同じソフトを持っている人同士なら、部屋コードでネット越しに対戦できます（空いた席はAIが入ります）。

- ユニット60種・シナジー36種（属性18＋職業18）
- ショップ・リロール・レベル上げ・★2/★3強化・利子・連勝/連敗ボーナス
- ホスト1人のPCが部屋を作り、ほかの人は部屋コードで参加
- 途中で切断した人の席はAIが引き継ぎます
- **ver 2.0：3D化**（Panda3D）。騎士・弓使い・魔法使い・竜人・機械兵・亡霊など15種類の見た目で、攻撃・スキル・被弾・倒れる動きつき
- **ver 2.0：ユニットの数値をサイトで編集**。exeを作り直さずに、スキル・ステータス・シナジー・経済を変えられます（下の「F」）

## F. ユニット・スキルの数値を変える（exeの作り直し不要）

数値はすべて `unit_data.json` に入っています。編集サイトで変えて、GitHubの `unit_data.json` を差し替えるだけでゲームに反映されます。

1. 編集サイトを開きます（claude.ai の「ヘックス・アリーナ編集室」、または このリポジトリの `editor/index.html` をブラウザで開く）。
2. 「ユニット」「スキル」「シナジー」「モンスター」「基本設定」のタブで数値を変えます。★2・★3の値やスキル威力は自動計算されて横に表示されます。
3. 「共有に保存」でチームの作業データとして保存できます（claude.ai 版のみ。履歴から前の版に戻せます）。
4. ゲームに反映するときは「JSONをコピー」→ GitHubで `unit_data.json` を開き、鉛筆マーク（編集）→ 全部選択して貼り付け →「Commit changes」。
5. ゲームを起動し直すか、タイトル画面の「最新データを読み込む」を押すと反映されます。

補足：
- ゲームは起動時にGitHubの最新 `unit_data.json` を読みます。ネットにつながらないときはexeに入っているデータを使います。
- 自分だけで試したいときは、`unit_data.json` を `HexArena.exe` と同じフォルダに置くとそちらが優先されます。
- 対戦では、ホストのデータが参加者全員に自動で配られます。
- 読み込めないデータ（職業名の打ち間違いなど）だった場合は、タイトル画面の右上に理由が赤字で出て、同梱データで動きます。
- `unit_data.json` だけを変えたときは、exeの自動作成（Actions）は動きません。

## A. exe（Windows用ソフト）の作り方　※おすすめ：GitHubで自動作成

自分のPCにPythonを入れなくても、GitHubが自動でexeを作り、ダウンロードページまで用意してくれます。友だちも同じページから同じソフトを入手できます。

1. https://github.com にアクセスし、無料アカウントを作ります。
2. 右上の「＋」→「New repository」を押します。
3. 名前（例：hexarena）を入れ、「Public」を選んで「Create repository」を押します。
4. 表示された画面の「uploading an existing file」をクリックします。
5. このzipを解凍したフォルダの **中身すべて**（main.py、assetsフォルダ、.githubフォルダ など）をドラッグ＆ドロップし、「Commit changes」を押します。
6. 上のメニューの「Actions」を開きます。黄色の丸が緑のチェックになるまで待ちます（5分ほど）。
7. リポジトリのトップページ右側の「Releases」を開き、「HexArena.exe」をダウンロードします。
8. 遊ぶ人全員に、このReleasesページのURLを伝えてダウンロードしてもらいます。

うまくいかないとき：
- 手順6で何も動かない場合、「.github」フォルダがアップロードされていない可能性があります。
  「Add file」→「Create new file」を押し、ファイル名に `.github/workflows/build.yml` と入力して、zip内の同じファイルの中身を貼り付けて保存してください。
- Actionsで「権限がない」と出る場合：「Settings」→「Actions」→「General」→ 一番下の「Workflow permissions」で「Read and write permissions」を選んで保存し、Actionsの画面で「Re-run jobs」を押してください。

## B. exeの作り方（予備：自分のWindows PCで作る）

1. https://www.python.org/ から Python 3.11 をインストールします（最初の画面で「Add python.exe to PATH」に必ずチェック）。
2. zipを解凍したフォルダの `build.bat` をダブルクリックします。
3. 数分待つと `dist` フォルダに `HexArena.exe` ができます。

## C. 遊び方（操作）

1. ショップのカードをクリックして購入 → ベンチに入ります。
2. ベンチのユニットを盤面の下半分へドラッグして配置します（置ける数＝レベル）。
3. 同じユニット3体で★2、★2を3体で★3に自動強化されます。
4. 左の「シナジー」一覧で、同じ特性がそろうとボーナスが付きます（マウスを乗せると説明が出ます）。
5. キー操作：D＝リロール(2G)、F＝経験値購入(4G)、E＝売却、Space＝準備OK、Esc＝メニュー
   カメラ：右ドラッグ＝回す、ホイール＝寄る・引く、Home＝元に戻す
6. 右のプレイヤー一覧をクリックすると、その人の盤面を見られます。

## D. みんなで対戦する方法

### ホスト（部屋を作る人）
1. `HexArena.exe` を起動し、名前を入れて「部屋を作る（ホスト）」を押します。
2. 初回に「Windowsセキュリティの重要な警告」が出たら「アクセスを許可する」を押します。
3. 画面に出た「部屋コード」を参加者に伝えます。
4. 全員が入ったら「ゲーム開始」を押します（空いた席はAIになります）。

### 参加者
1. `HexArena.exe` を起動し、名前を入れて「部屋に入る」を押します。
2. ホストから聞いた部屋コードを入力（Ctrl+Vで貼り付け可）して「入る」を押します。

### どの部屋コードを使う？
| 状況 | 使うコード |
|---|---|
| 同じWi-Fi・同じ社内LAN | 「同じWi-Fi・社内LAN・VPNツールで遊ぶ用」 |
| 離れた場所（おすすめ） | 全員で無料VPNツール（Radmin VPN など）を使い、VPNのアドレス（26.から始まる等）のコード |
| 離れた場所（ルーター設定できる人向け） | ホストのルーターで「TCP 7777番」をポート開放し、「ネット越しで遊ぶ用」のコード |

**Radmin VPN を使う手順（ポート開放不要でいちばん簡単）**
1. 全員が https://www.radmin-vpn.com/jp/ からRadmin VPNをインストールします。
2. ホストが「ネットワーク」→「ネットワークを作成」で名前とパスワードを決めます。
3. 参加者は「ネットワーク」→「既存のネットワークに参加」で同じ名前とパスワードを入れます。
4. ホストはゲームで「部屋を作る」を押し、表示されたコードのうち（26.xx.xx.xx）のものを伝えます。

### 注意
- 全員が **同じバージョン（同じビルド）** のexeを使ってください。違うと参加できません。
- ホストがゲームを終了すると、全員のゲームが終わります。

## E. ファイル構成
| ファイル | 内容 |
|---|---|
| main.py | 画面・操作（3Dの上に文字やボタンを重ねて表示） |
| world3d.py | 3Dの盤面・闘技場・カメラ・演出 |
| models3d.py | ユニットの3Dモデル（プログラムで組み立て） |
| game.py | ゲーム進行（ショップ・経済・ラウンド） |
| combat.py | 自動戦闘の計算 |
| ai.py | AIプレイヤー |
| net.py | 通信・部屋コード |
| data.py | データの読み込み・計算式 |
| unit_data.json | ユニット・スキル・シナジー・モンスター・経済の数値（編集サイトで編集） |
| editor/index.html | 数値の編集サイト |
| assets/ | 日本語フォント（Noto Sans JP, OFLライセンス） |

Pythonで直接起動する場合：`pip install -r requirements.txt` のあと `python main.py`
うまく動かないときは、exeと同じフォルダに `hexarena_error.log` ができていないか確認してください。
